# Security policy (pre-implementation)

There are no released or supported service versions yet. Do not send live
credentials, private replays or exploit details to public issues.

Before any external release, configure and test a private vulnerability-reporting
channel, response ownership, incident escalation and disclosure process. No
reporting address or response SLA is claimed until actually configured.

Release requires independent review of the integrated authentication, vault,
authorization and migration design; upstream library audits are insufficient.
Outstanding severe findings block release. Record review scope, versions,
remediation and residual risks without exposing exploitable production details.
